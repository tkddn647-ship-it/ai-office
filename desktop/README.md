# AI Office Desktop

내 PC에서 돌아가는 AI 코딩 에이전트 팀입니다. AI 셋이 **기획 → 구현 → 테스트 → 리뷰 → 수정**을 나눠 맡고, 마지막 승인은 사람이 합니다.
GitHub 버전 AI Office와 같은 원칙으로, 서버 없이 Windows 프로그램 하나로 동작합니다.

## 시작하기
1. 릴리스에서 `AIOfficeDesktop.exe`를 받아 실행합니다. 검은 창이 뜨고 브라우저에 화면이 열립니다. 검은 창을 닫으면 프로그램이 끝납니다.
   - 서명되지 않은 프로그램이라 처음 실행할 때 Windows SmartScreen 경고가 뜰 수 있습니다. "추가 정보 → 실행"을 누르세요.
2. 왼쪽에서 **작업 폴더**를 고르고, 필요하면 **테스트 명령**을 적습니다. 예: `python -m pytest -q`, `npm test`
3. **역할별 AI**를 고릅니다. 팀장·개발·리뷰마다 OpenAI, Anthropic, Google Gemini 중 하나와 모델 이름을 정합니다.
4. 쓰는 회사의 **API 키**를 넣고 저장합니다.
5. 아래 칸에 할 일을 적고 **시작**을 누릅니다.

키 없이 흐름만 보려면 세 역할 모두 "테스트용 가짜 AI"를 고르세요. 작업 폴더에 `AI_OFFICE_DEMO.md` 하나를 만들었다가, 버리기를 누르면 지웁니다.

## 흐름
| 단계 | 하는 일 |
|--|--|
| 팀장 | 요청을 작업 최대 3개로 나누고, 작업마다 읽을 파일을 고릅니다. 파일은 고치지 않습니다. |
| 개발 | 작업마다 파일을 고칩니다. 편집은 작업 폴더 안에서만 적용됩니다. |
| 테스트 | 설정한 테스트 명령을 실행합니다. |
| 리뷰 | 바뀐 내용과 테스트 결과를 보고 승인하거나 고칠 점을 적습니다. 파일은 고치지 않습니다. |
| 수정 라운드 | 리뷰가 고칠 점을 적거나 테스트가 실패하면, 정한 횟수만큼 개발이 다시 고칩니다. |
| 사람 | **변경 보기**로 diff를 확인하고 **승인** 또는 **버리기**를 누릅니다. |

승인을 누르면 작업 폴더가 git 저장소일 때 `ai-office/날짜-시각` 새 브랜치에 바뀐 파일만 커밋합니다. git 저장소가 아니면 파일만 바뀐 채로 둡니다.
버리기를 누르면 이번 작업에서 바뀐 파일을 모두 원래대로 되돌립니다.

## 안전 장치
- 작업 폴더 밖 경로, 절대 경로, `.git` 안쪽은 읽지도 쓰지도 않습니다.
- AI가 직접 셸 명령을 실행하지 않습니다. 실행되는 명령은 사용자가 적은 테스트 명령 하나뿐입니다.
- 한 번 실행에 AI 호출 수 한도가 있습니다. 기본값은 12회입니다.
- 화면 서버는 이 PC(127.0.0.1)에서만 열리고, 실행할 때마다 만든 토큰이 없으면 API가 동작하지 않습니다.

## API 키와 비용
- 키는 Windows 자격 증명 관리자에 저장합니다. 저장이 안 되는 환경에서는 `%APPDATA%\AIOfficeDesktop\keys.json`에 저장하고 화면에 그 위치를 표시합니다.
- 키는 각 회사 API로만 보내고, 화면에 다시 표시하지 않습니다.
- **요금은 키 주인에게 청구됩니다.** 실행이 끝나면 역할별 호출 수와 입력·출력 토큰 수를 화면에 보여 줍니다.
- 모델 이름은 각 회사 문서에서 확인해 넣으세요. 기본값은 예시이고, 회사가 모델을 바꾸면 달라질 수 있습니다.

## 한계
- 큰 저장소는 파일 목록과 고른 파일 내용만 보냅니다. 한 번에 보내는 파일 내용은 약 12만 자까지입니다.
- 텍스트 파일만 다룹니다. 이미지·바이너리 파일은 보지 않습니다.
- AI가 고친 코드는 틀릴 수 있습니다. 승인 전에 diff를 꼭 확인하세요.

## 직접 빌드
```bat
cd desktop
pip install pyinstaller -r requirements.txt
python -m unittest -v tests/test_desktop.py
pyinstaller --onefile --name AIOfficeDesktop --add-data "aio_desktop/static;aio_desktop/static" --hidden-import keyring.backends.Windows run.py
```
소스로 바로 실행: `python -m aio_desktop` (desktop 폴더에서)
