사람 확인 차례입니다.
작업 폴더의 requirements*.txt(== 고정), Pipfile.lock, poetry.lock, package-lock.json을 읽어 부품 목록을 만들고 OSV·CISA KEV·FIRST EPSS 공개 자료로 등급을 매깁니다. 등급은 규칙이 계산하고, AI는 긴급·우선 항목의 조치안 문장만 씁니다. 코드는 바꾸지 않고 보고서만 ai-office-security 폴더에 남깁니다. AI에는 패키지 이름·버전·취약점 정보만 보내고 소스 코드는 보내지 않습니다.
경험 기록 폴더의 .md·.txt만 근거로 씁니다. 기록에 없는 수치·역할은 [확인 필요]로 남깁니다. 경험 기록과 공고 내용이 고른 AI 회사로 전송됩니다. 무료 요금제는 입력을 사람이 검토하거나 학습에 쓸 수 있으니, 주민번호·연락처 같은 정보는 기록에서 빼 주세요.
