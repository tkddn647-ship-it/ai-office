AI Office Desktop

자료 폴더

경험·지원서·답이 이 폴더에 파일로 저장됩니다. GitHub 버전(for_office) 폴더를 고르면 기존 experiences/ 경험 기록을 그대로 씁니다. 바꾼 뒤 설정 저장을 누르세요.
